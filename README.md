
# 🤖 VR Zion VK Bot

Бот для автоматического создания отложенных постов в сообществе VK для арены виртуальной реальности **VR Zion** (г. Тула, ул. Тургеневская 69Б).

## ✨ Возможности

- 🎂 **Пост про день рождения** — бот собирает данные (имя, возраст, дата, факт) и генерирует поздравление через Yandex GPT
- ✍️ **Свободный пост** — создание любого поста по описанию от оператора
- 📅 **Выбор времени публикации** — вручную (ДД.ММ ЧЧ:ММ) или кнопкой "Завтра"
- 📸 **Загрузка медиа** — поддержка JPG, PNG, HEIC (автоконтвертация), MP4, MOV
- 📦 **Пакетная загрузка** — можно отправлять несколько файлов сразу
- 🔐 **Мульти-пользовательская авторизация (PKCE)** — каждый сотрудник авторизуется через бота, токены хранятся в защищенной БД
- 🔄 **Автообновление и проверка токенов** — бот сам обновляет токены и проверяет их валидность перед публикацией
- 👥 **Уведомления операторам** — все созданные посты автоматически анонсируются
- 🛡 **Белый список пользователей** — доступ только для авторизованных сотрудников

## 🔐 Настройка `.env`

Создайте файл `.env` в корне проекта. Значения пишите **без кавычек**, ID указывайте через запятую **без пробелов**.

```env
# === Токен сообщества (вечный, из настроек группы) ===
VK_GROUP_TOKEN=vk1.a.ваш_ключ

# === Данные приложения VK (ОБЯЗАТЕЛЬНО для PKCE авторизации сотрудников) ===
VK_CLIENT_ID=123456789
VK_CLIENT_SECRET=ваш_длинный_секретный_ключ

# === ID группы и пользователей ===
VK_GROUP_ID=219995441
ADMIN_USER_IDS=6510108,123456789
OPERATOR_USER_IDS=6510108,3912478

# === Yandex GPT ===
YA_API_KEY=ваш_api_key
YA_FOLDER_ID=ваш_folder_id

# === Прочее ===
UPLOAD_DIR=media
```

> ⚠️ **Важно:** Переменные `VK_USER_TOKEN`, `VK_REFRESH_TOKEN` и т.д. больше **не нужны** в `.env`. Теперь каждый сотрудник получает свой токен через бота, и они хранятся в файле `users.db`.

### Где взять данные:
| Переменная | Где взять |
|---|---|
| `VK_GROUP_TOKEN` | Настройки сообщества → Работа с API → Создать ключ |
| `VK_CLIENT_ID` | [dev.vk.com](https://dev.vk.com) → ID приложения |
| `VK_CLIENT_SECRET` | Там же → Защищённый ключ (Secret key) |
| `YA_API_KEY` / `YA_FOLDER_ID` | [Yandex Cloud](https://console.cloud.yandex.ru/) |

## 🔑 Авторизация сотрудников (Новая система)

Больше не нужно использовать скрипты для получения токена. Всё делается прямо в диалоге с ботом.

### Для нового сотрудника:
1. Напишите боту `/start`.
2. Так как токена нет, бот покажет одну кнопку: **🔐 Авторизация**.
3. Нажмите на неё. Бот выдаст специальную ссылку.
4. Перейдите по ссылке, войдите в VK и нажмите **"Разрешить"**.
5. После разрешения браузер откроет пустую страницу. **Скопируйте ВЕСЬ URL из адресной строки** (он будет содержать параметры `code=...` и `device_id=...`).
6. Отправьте эту ссылку боту в чат.
7. Готово! Бот подтвердит успешную авторизацию. Теперь вы можете создавать посты и прикреплять свои видео.

## 🖥 Запуск в продакшене 24/7

### Вариант А: Windows (через NSSM)
**NSSM** (Non-Sucking Service Manager) — утилита для запуска Python-скриптов как службы Windows.

1. Скачайте NSSM: [nssm.cc/download](https://nssm.cc/download)
2. Распакуйте в любую папку (например, `C:\nssm\`).
3. Установите службу (запустите CMD **от имени администратора**):
   ```cmd
   C:\nssm\win64\nssm install VRZionBot
   ```
4. В открывшемся окне заполните:
   - **Path:** `C:\Путь\К\Python\python.exe` (или `.venv\Scripts\python.exe`)
   - **Startup directory:** `C:\Путь\К\vk-bot-zion`
   - **Arguments:** `-m app.bot`
5. Вкладка **"I/O"**: укажите пути для логов (например, `C:\Путь\К\vk-bot-zion\logs\out.log`).
6. Нажмите **"Install service"**.
7. Управление:
   ```cmd
   nssm start VRZionBot      # Запустить
   nssm restart VRZionBot    # Перезапустить
   nssm edit VRZionBot       # Редактировать настройки
   ```

### Вариант Б: macOS (через launchd)
1. Создайте файл `~/Library/LaunchAgents/com.vrzion.bot.plist`:
   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0">
   <dict>
       <key>Label</key><string>com.vrzion.bot</string>
       <key>ProgramArguments</key>
       <array>
           <string>/Users/natalia/Репозиторий/vk-bot-zion/.venv/bin/python</string>
           <string>-m</string>
           <string>app.bot</string>
       </array>
       <key>WorkingDirectory</key><string>/Users/natalia/Репозиторий/vk-bot-zion</string>
       <key>RunAtLoad</key><true/>
       <key>KeepAlive</key><true/>
       <key>StandardOutPath</key><string>/Users/natalia/Репозиторий/vk-bot-zion/logs/out.log</string>
       <key>StandardErrorPath</key><string>/Users/natalia/Репозиторий/vk-bot-zion/logs/err.log</string>
   </dict>
   </plist>
   ```
2. Создайте папку для логов: `mkdir -p logs`
3. Загрузите службу: `launchctl load ~/Library/LaunchAgents/com.vrzion.bot.plist`
4. Управление: `launchctl start/stop com.vrzion.bot`

### Вариант В: Linux (через systemd)
Создайте файл `/etc/systemd/system/vrzion-bot.service`:
```ini
[Unit]
Description=VR Zion VK Bot
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/vk-bot-zion
ExecStart=/opt/vk-bot-zion/.venv/bin/python -m app.bot
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```
Запуск: `sudo systemctl enable --now vrzion-bot`

## 🔧 Обслуживание и перенос

### Перенос бота на другой сервер (Windows/macOS/Linux)
1. Скопируйте всю папку проекта, включая файл `.env` и **файл базы данных `users.db`**.
2. Запустите бота на новом сервере.
3. Попросите сотрудников написать боту команду `/check`.
4. Если токены всё ещё валидны, бот подтвердит это, и работа продолжится без сбоев.
5. Если токен протух (например, из-за смены IP или долгого простоя), бот сообщит об этом и предложит написать `/auth` для быстрой повторной авторизации.

### Частые проблемы
| Проблема | Решение |
|---|---|
| `User authorization failed: invalid access_token` | Токен конкретного пользователя протух. Пусть он напишет боту `/reauth` и пройдет авторизацию заново. |
| Бот не прикрепляет видео | Убедитесь, что пользователь прошел `/auth`. Видео, отправленные неавторизованными пользователями, VK блокирует. |
| Бот не отвечает на сообщения | Проверьте, что ваш VK ID добавлен в `ADMIN_USER_IDS` в файле `.env`, и перезапустите бота. |
| HEIC не загружается | Убедитесь, что установлен `pillow-heif`: `pip install pillow-heif` |

## 🛡 Безопасность

- **Никогда не коммитьте `.env` и `users.db` в git!** Они уже добавлены в `.gitignore`.
- **Храните `VK_CLIENT_SECRET` в секрете** — он дает право на обновление токенов.
- **Используйте `ADMIN_USER_IDS`** — только указанные ID могут взаимодействовать с ботом.
- База данных `users.db` хранит токены в зашифрованном виде (стандарт SQLite), доступ к файлу должен быть только у пользователя, запускающего бота.

## 📝 Использование (для сотрудников)

1. **Первичная настройка:** Если вы новый сотрудник, напишите боту `/auth` и следуйте инструкциям для привязки вашего аккаунта.
2. Напишите боту: `/start`
3. Выберите тип поста:
   - 🎂 **Пост про день рождения** → введите 4 строки данных
   - ✍️ **Свободный пост** → опишите тему в свободной форме
4. Утвердите сгенерированный текст (или нажмите "Редактировать" / "Перегенерировать")
5. Укажите время публикации (или нажмите "📅 Завтра в это же время")
6. Пришлите фото или видео **отдельным сообщением** (можно несколько файлов сразу). *Важно: видео должны быть вашими или уже загруженными в группу.*
7. Нажмите кнопку **"Готово к публикации"**

Готово! Пост появится в сообществе в указанное время, а операторы получат уведомление.

---
### Скрытые команды управления токеном:
Эти команды полезны при переносе бота на новый сервер или если токен внезапно перестал работать.

| `/check` (или `/статус`) | Делает реальный запрос к VK API и сообщает, валиден ли ваш токен. Если нет — автоматически удаляет его из базы. |
| `/reauth` (или `/переавторизация`) | Принудительно удаляет старый токен из базы и запускает процесс новой авторизации. |
